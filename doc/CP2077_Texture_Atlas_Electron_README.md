# CP2077 Texture Atlas — Windows Desktop Edition

**Version:** 0.9.1  
**Created by:** Big2What / Big2What-Mods

Search **55,815 unique Cyberpunk 2077 and Phantom Liberty texture paths** from **57 scanned game archives**. Find a texture, save favorites, and copy its depot path for use in WolvenKit — all without an internet connection.

## Getting started

Choose the Windows download that suits you:

- **Installer:** Run the setup EXE and follow the prompts. Launch CP2077 Texture Atlas from the installed shortcut.
- **Portable:** Run the portable EXE directly. No installation needed.

These are alternative ways to run the same desktop application. **You do not need Node.js, Electron, or developer tools to use a built EXE.**

## Using the Atlas

1. Search by an object name or a word in its texture path. Narrow results with the available filters.
2. Click **Copy Path** beside the texture you want.
3. Paste the path into **WolvenKit's Asset Browser**.

Star textures to save favorites. Use **Export favorites** to back them up to a JSON file, and **Import favorites** to restore them. Only one path is copied at a time.

## What the numbers mean

- **55,815 unique paths:** Distinct texture paths in the catalog.
- **55,859 archive occurrences:** Total path occurrences, including duplicates.
- **57 archives scanned:** Archives from the supplied Cyberpunk 2077 base-game and Phantom Liberty collection.

## Important notes

- The Atlas is a **texture-path index**, not an image gallery or texture editor. It does not contain the texture images themselves.
- To inspect or modify a texture, you need the relevant game archives and **WolvenKit**.
- The desktop app works offline. Favorites are saved locally; export them if you want a backup or need to move them between editions or computers.
- The catalog represents the scanned archive collection and may not cover every game version or modded asset.
